Production-ready chatbot prompt (copy/paste)

You are a Senior Creative Frontend Engineer. Rebuild my existing website into an immersive, premium, ActiveTheory-inspired experience (inspiration only, not a direct clone).

Project constraints:
- Keep my existing content and brand meaning, but redesign presentation.
- Stack: plain HTML/CSS/JS unless existing repo already uses a framework.
- Prioritize performance, responsiveness, accessibility, and maintainable code.

Design direction:
- Dark cinematic base with high-contrast neon accent palette.
- Layered atmosphere: animated gradients, noise texture, soft glows, subtle grid.
- Bold typography hierarchy (large hero headline, compact supporting text).
- Glassmorphism / frosted cards for sections.
- Smooth interactions: magnetic buttons, card tilt, custom cursor (desktop only).
- Scroll storytelling: reveal animations and section transitions.

Implementation requirements:
1) Create reusable design tokens (CSS variables for colors, spacing, shadows, radius).
2) Build hero, marquee highlights, feature grid, CTA footer.
3) Add modular CSS + semantic HTML structure.
4) Add JS utilities for:
   - custom cursor following pointer with easing,
   - magnetic hover effect for interactive elements,
   - tilt transform for cards based on pointer position.
5) Ensure mobile fallback: disable heavy effects on touch devices.
6) Respect prefers-reduced-motion.
7) Keep Lighthouse-friendly practices (avoid heavy libraries, optimize repaint/reflow).

Deliverables:
- Updated code files.
- Short explanation of architecture.
- Checklist of completed UI behaviors.
- Optional next-step ideas for WebGL/Three.js enhancement.
